# Tharun Gowda G — AIML Learning Hub

A beginner-friendly student website for collecting free programming-learning resources.

## Files
- index.html — website structure and content
- style.css — responsive design and dark mode styling
- script.js — dark mode and practice-answer interaction

## Important
The website links to public YouTube search pages rather than copying/re-uploading videos. To add a specific tutorial, replace a YouTube search URL with the creator's official video URL.

## Publish
You can publish this as a static website using GitHub Pages, Netlify, or Vercel. After deployment, the site gets a public web address that can be opened in Chrome.
