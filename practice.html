Calculator

Write a Python program that accepts two numbers and an operation (+, -, *, /), then prints the result.

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
operation = input("Enter +, -, * or /: ")

if operation == "+":
    print(a + b)
elif operation == "-":
    print(a - b)
elif operation == "*":
    print(a * b)
elif operation == "/":
    print(a / b)
else:
    print("Invalid operation")
